
# Python Task Manager

A command-line task manager built with Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks locally in a JSON file
- Handle invalid user input

## Requirements

- Python 3
- No external packages required

## How to Run

```bash
python task_manager.py
```

## Run Tests

```bash
python -m unittest -v
```

- Python
- JSON
